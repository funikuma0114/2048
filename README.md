# 2048

ブラウザで動く 2048 ゲームです。キーボード（← ↑ → ↓）とスマホのスワイプ操作に対応しています。

## ローカルで動かす

`index.html` をブラウザで開くだけで遊べます。

## GitHub Pages で公開する

1. このリポジトリを GitHub に push
2. GitHub の **Settings > Pages** を開く
3. **Build and deployment** で次を選択
   - Source: `Deploy from a branch`
   - Branch: `main`（または作業ブランチをマージしたブランチ）
   - Folder: `/ (root)`
4. 保存後、数分待つと公開 URL でアクセスできます
